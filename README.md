# 📊 Wireshark Network Traffic Analysis

This project focuses on capturing and analyzing local network traffic to inspect fundamental network communication protocols in a virtualized environment.

---

### 🔍 Key Analysis & Insights

- **mDNS (Multicast Domain Name System):** Examined local device discovery queries and standard query responses to monitor local hostname resolutions.
- **DHCP (Dynamic Host Configuration Protocol):** Analyzed client-server IP request (`DHCP Request`) and lease acknowledgment (`DHCP ACK`) transactions.
- **Ethernet & Frame Inspection:** Inspected Ethernet II frame headers, MAC address maps, and traffic statistics across active endpoints.
- **Conclusion:** Verified standard background operations on the local subnet with no suspicious or anomalous external connections.
